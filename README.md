
This project is part of the BAISH x BlueDotImpact Technical AI Safety Project course hosted in Buenos Aires. 

This is a Mechanistic Interpretability research on Jailbreaks based on fiction. There are different studies that show how jailbreaks are done by suppressing the refusal direction ([https://arxiv.org/abs/2411.11114](https://arxiv.org/abs/2411.11114)), and how directions like role-play/assistant (https://arxiv.org/abs/2601.10387](https://arxiv.org/abs/2601.10387)) can produce harmful/harmless behaviour by steering. 
Based on [From Adversarial Poetry to Adversarial Tales: An Interpretability Research Agenda](https://arxiv.org/abs/2601.08837) , we see that jailbreaks might be successful because they embed harmful requests inside fictional stories, so do jailbreaks generally work by detecting the prompts are just part of a story? Can we steer away this behaviour? Is it a different direction from role-play/assistant?
